# 이름이 다른 남녀 아이템 대응 검토

검토일: 2026-10-31. 원본 상점 31,062개 중 공개 아이템 14,090개를 조사했다.

## 판정 근거

- `rnr_script/config/items_tbitems.json`의 `code`를 상점 Index에 연결하고 원래 이름의 남녀 표기를 대조했다. 성별ㆍ부위ㆍ일반/성인 캐릭터 구분을 유지하고, 숨김 아이템까지 포함해 이름 중복을 확인했다.
- 원래 이름으로 유일하게 대응하는 공개 299쌍 중 242쌍은 기존 대응과 일치했다. 새로운 후보 57쌍을 썸네일과 대조했다.
- `face.txt`의 얼굴 리소스와 한국어의 성별 표현ㆍ띄어쓰기 차이도 조사했다. 번호 인접성이나 모델 번호 일치만으로 연결하지 않았다.
- 총 202개 후보쌍의 이미지를 검토했다. 동일 디자인ㆍ무늬ㆍ특징이나 원래 이름의 명확한 남녀 버전을 확인한 169쌍을 연결하고, 불확실한 33쌍은 보류했다. 성별 버전에는 색상ㆍ길이ㆍ실루엣 차이가 있을 수 있다.
- `items_tbclothingchangemap.json`은 로비/인게임 의상 변환표이다. 남녀 대응표로 사용하지 않았다. `setavatareffect.xml`과 `avatarcollect.xml`의 대응 항목은 현재 숨김 상태여서 이번 공개 아이템 연결의 근거로 사용하지 않았다.
- 기존 카탈로그ㆍ아이템 번호ㆍ가격ㆍ모델ㆍURLㆍ즐겨찾기 데이터는 보존한다. 검토된 대응은 별도 읽기 전용 목록에서 보완하며, 기존 대응이 있으면 우선한다. DB 변경은 필요하지 않았다. 성인 모델의 미리보기 가능 여부도 바꾸지 않는다.
